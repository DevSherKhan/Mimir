# Governance

Mimir currently follows a maintainer-led governance model.

- Maintainers set project direction, review contributions, manage releases, and handle security reports.
- Significant changes should begin with a public issue or proposal so tradeoffs can be discussed before implementation.
- Decisions prioritize user privacy, tenant isolation, backward compatibility, operational simplicity, and a narrow hosted MCP security surface.
- Contributors who demonstrate sustained, constructive participation may be invited to become maintainers.

Governance may evolve as the contributor community grows. Material changes to this document will be proposed publicly.
