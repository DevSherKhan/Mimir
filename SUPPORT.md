# Support

For setup questions, feature discussions, and troubleshooting that does not contain sensitive data, use [GitHub Discussions](https://github.com/DevSherKhan/Mimir/discussions) or open a regular issue.

Before requesting help, run:

```bash
mimir doctor
mimir status
npm run check
```

Never post access tokens, `.env` contents, database URLs, API keys, private chat text, or local database files. Report security problems privately as described in [SECURITY.md](SECURITY.md).
